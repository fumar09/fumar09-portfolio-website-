# Portfolio video files

Place your video files in this folder. The site reads them from `/videos/...`.

- Video introduction: `public/videos/introduction.mp4`
- Client testimonials: `public/videos/client-testimonial-01.mp4`, `client-testimonial-02.mp4`, and so on

After adding a file, configure its path and display details in `src/data/videoContent.ts`. The Testimonials page will show the video player when an entry is configured.
